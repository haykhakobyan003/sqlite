# MiniSQL (C)

Պարզ ուսումնական տվյալների բազա, որն աշխատում է տերմինալում և պահպանում է աղյուսակներն ու գրառումները `database.json` ֆայլում՝ առանց SQLite-ի։

## Գործարկում

1. Բացեք տերմինալը `mini_sql.c` ֆայլի պանակում։
2. Կոմպիլացրեք՝
   ```bash
   gcc -std=c11 -Wall -Wextra mini_sql.c -o mini_sql
   ```
3. Գործարկեք՝
   ```bash
   ./mini_sql
   ```
4. Մուտքագրեք հրամանները՝ յուրաքանչյուր SQL հրամանը մեկ տողով և վերջում `;` նշանով։ Ավարտելու համար գրեք `.exit`։

Առաջին գործարկման ժամանակ ստեղծվում է դատարկ `database.json`։ Տվյալները պահպանվում են յուրաքանչյուր հաջող փոփոխությունից հետո և վերականգնվում հաջորդ գործարկման ժամանակ։

## Աջակցվող հրամաններ

```sql
CREATE TABLE students (id INTEGER, name TEXT, age INTEGER);
INSERT INTO students VALUES (1, 'Ani', 20);
SELECT * FROM students;
SELECT * FROM students WHERE id = 1;
UPDATE students SET age = 21 WHERE id = 1;
DELETE FROM students WHERE id = 1;
```

Ծառայողական հրամաններ (առանց `;`)՝ `.help`, `.tables`, `.exit`։

## Սահմանափակումներ

- Տվյալների տեսակները՝ միայն `INTEGER` և `TEXT` (տեքստը՝ մեկ չակերտների մեջ)։
- `WHERE`-ը աջակցում է միայն մեկ `սյունակ = արժեք` պայման։ `UPDATE`-ը փոխում է մեկ սյունակ։ Համընկնող բոլոր տողերը մշակվում են։
- Առավելագույնը **20 աղյուսակ**, **16 սյունակ յուրաքանչյուր աղյուսակում**, **10 000 տող յուրաքանչյուր աղյուսակում**։ Անունները՝ առավելագույնը 63 նիշ, տեքստային արժեքները՝ 255 նիշ։
- SQL բանալի բառերը մեծատառերից/փոքրատառերից կախված չեն։ Աղյուսակների և սյունակների անունները պետք է կազմված լինեն լատինատառ տառերից, թվերից և `_`-ից։
- Չկան `JOIN`, `ORDER BY`, `NULL`, ինդեքսներ, տրանզակցիաներ, `id`-ի ավտոմատ համարակալում կամ եզակիության պարտադրանք։ Տեքստի ներսում չակերտների հատուկ մշակում չկա։
- Սխալ հրամանը ցուցադրում է հաղորդագրություն և չի դադարեցնում ծրագիրը։
